# Configuration réseau avec EIGRP

## Présentation
Ce projet a été réalisé dans le cadre de ma formation en Techniques de l'informatique au Collège LaSalle.

L'objectif est de pratiquer la configuration d'un réseau informatique à l'aide du protocole de routage dynamique EIGRP.

## Objectifs
- Configurer les interfaces des routeurs.
- Attribuer les adresses IPv4.
- Configurer le protocole EIGRP.
- Vérifier la communication entre les réseaux.
- Tester la connectivité avec des commandes de diagnostic.

## Technologies utilisées
- Cisco Packet Tracer
- Routage EIGRP
- Adressage IPv4
- Commandes Cisco IOS

## Compétences développées
- Configuration des routeurs.
- Compréhension du routage dynamique.
- Dépannage réseau.
